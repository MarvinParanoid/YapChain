# refgen — независимый генератор test vectors

Генерирует `test-vectors/*.json` эталонной реализацией на чистом Python (только стандартная библиотека;
SHA-2 — из `hashlib`). Код не разделяется ни с C++-ядром, ни с libsodium — поэтому совпадение C++ с векторами
является независимой проверкой.

```sh
python3 -I tools/refgen/refgen.py --out test-vectors
```

| Модуль | Что реализует |
|---|---|
| `ed25519_ref.py` | Ed25519 по RFC 8032 и нормативный алгоритм проверки docs/protocol.md §5.2 (ADR-0014) |
| `bech32m_ref.py` | Bech32m (BIP-350) и адреса YapChain (docs/protocol.md §5.3) |
| `ycs_ref.py` | YCS (docs/protocol.md §3) для тестовых схем |
| `refgen.py` | SHA-256, tagged hash, арифметика, сборка всех файлов |

Генератор сам проверяет известные ответы (NIST SHA-256, RFC 8032 §7.1, BIP-350) и падает, если эталон
разошёлся с ними. CI проверяет, что повторный запуск даёт побайтно те же файлы.
