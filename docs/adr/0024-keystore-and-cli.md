# ADR-0024: Keystore и CLI `yap`

**Статус:** DECIDED (M1.4) · реализует protocol.md §5.6; формат файла локальный, не консенсусный

## Keystore
JSON с полями ровно из §5.6 плюс два открытых поля: `purpose` и `public_key`.

```
{ "version": 1, "purpose": "account" | "dev-producer", "kdf": "argon2id",
  "opslimit": "u64", "memlimit": "u64", "salt": hex16, "nonce": hex24,
  "ciphertext": hex48, "public_key": hex32, "address": "tyap1…" }
```

- Seed (32 байта) из CSPRNG ОС, хранится только в памяти `sodium_malloc`, шифруется XChaCha20-Poly1305 ключом
  Argon2id (`crypto_pwhash`, уровень MODERATE в CLI).
- **AAD** = `"YAPCHAIN/KEYSTORE/V1\0" ‖ purpose ‖ u64 opslimit ‖ u64 memlimit ‖ salt ‖ public_key`:
  подмена любого открытого поля ломает расшифровку. `address` проверяется как производное от `public_key`.
- Параметры KDF принимаются только в диапазоне INTERACTIVE…SENSITIVE (защита от ослабленных файлов и от DoS).
- Неверный пароль и повреждённый шифротекст неразличимы (`wrong password or corrupted keystore`); чтение
  никогда не изменяет файл.
- Файлы ключей — `0600` в каталогах `0700`, запись атомарная (`O_EXCL` + `link`), существующий ключ не
  перезаписывается; файл, доступный группе или остальным, не читается.

## Разделение ключей
| Назначение | Где | Кто использует |
|---|---|---|
| `account` | `<home>/keys/<name>.json` | `yap keys`, `yap tx` |
| `dev-producer` | `<home>/dev/producer.json` | только `yap dev` |
| консенсусные ключи валидаторов | у CometBFT (M2) | `yap` с ними не работает |

Ключ другого назначения отвергается (`WrongPurpose`), даже если пароль верный.

## Пароли
Никогда не передаются аргументом. Источники по порядку: `--password-file` (файл `0600`), терминал без эха,
одна строка stdin (для автоматизации). При создании — не короче 8 символов.

## CLI
- Вывод: строки `ключ: значение` (стабильный машиночитаемый формат).
- Коды выхода: 0 — успех, 1 — ошибка командной строки, 2 — неверные данные или отклонённая транзакция/блок,
  3 — ошибка или порча хранилища, 4 — аутентификация (пароль, keystore), 5 — внутренняя ошибка.
- Мнемоники и HD-кошельки в M1 не поддерживаются (protocol.md §5.6, OPEN).
