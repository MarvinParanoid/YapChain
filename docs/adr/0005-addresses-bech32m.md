# ADR-0005: Адреса — хеш ключа + Bech32m

**Статус:** PROPOSED (формат Bech32m — DECIDED в постановке)

## Решение
`account_id = H_tag("YAP/addr/v1", 0x00 || pubkey)` (32 байта); строковый адрес — Bech32m (BIP-350),
HRP `tyap` (testnet) / `yap` (mainnet, резерв), версия адреса `0` первым символом данных. В консенсусных
структурах — только 32-байтовый `account_id`.

## Альтернативы
- pubkey как адрес — короче путь проверки, но жёстко привязывает адрес к одному алгоритму.
- 20-байтовый хеш — короче строка, но ~80 бит стойкости к коллизиям; для 32 байт длина строки (64 символа) всё равно в пределах лимита BIP-350.

## Последствия
Tx содержит pubkey отправителя (32 байта); отправитель выводится из него, отдельного поля sender нет.
Ротация ключа без смены адреса невозможна (сознательно, ради простоты).
