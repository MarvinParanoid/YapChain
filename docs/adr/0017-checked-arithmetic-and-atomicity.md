# ADR-0017: Checked-арифметика, классы ошибок и атомарность транзакций

**Статус:** DECIDED (ревизия M0)

## Проблема
В r1 checked-арифметика была объявлена, но не было сказано, чем заканчивается переполнение в разных местах;
были сравнения, которые сами могли переполниться (`H + max_tx_ttl_blocks`, `issued_at_s ≤ t + skew`,
`spent + reward`); атомарность tx была описана только как «никаких изменений state».

## Решение
- Внутри tx: любая арифметическая ошибка → `ERR_OVERFLOW`, overlay tx отбрасывается.
- Вне tx (эмиссия, `ChainState`, `InitChain`): fail-stop.
- Сравнения переписаны без переполнения (`a − b ≤ c` после проверки `a ≥ b`).
- Добавлена проверка `nonce < U64_MAX` (T4).
- Каждая tx исполняется в своём overlay (protocol.md §7.5); отказ хранилища — fail-stop, не ошибка tx.
