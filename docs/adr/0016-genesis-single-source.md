# ADR-0016: Genesis — единый источник в app_state CometBFT

**Статус:** DECIDED (ревизия M0)

## Проблема
r1 предполагал отдельный genesis YapChain и «сгенерированный из того же источника» genesis CometBFT. Два файла
могут разойтись (валидаторы, chain_id, время), а правила разбора JSON (числа, регистр, лишние поля) не были заданы —
разные реализации могли получить разный `Genesis` из одного файла.

## Решение
- Genesis YapChain — JSON в поле `app_state` genesis CometBFT; `InitChain` сверяет chain_id, `initial_height = 1`,
  время и набор валидаторов (protocol.md §11.4), любое несовпадение — fail-stop.
- Строгий JSON: `u64` — только десятичные строки без знаков и ведущих нулей; неизвестные и повторяющиеся ключи — ошибка.
- `genesis_hash` — только по YCS.
- Полные правила валидации — protocol.md §11.2, параметры — §12.
