# ADR-0018: Фиксация зависимостей через CMake (URL + SHA-256)

**Статус:** DECIDED (M1.1) · заменяет предложение vcpkg из architecture.md r1

## Контекст
Требование — зафиксированные, воспроизводимые зависимости на x86_64 и aarch64. vcpkg требует отдельного инструмента
и baseline-репозитория; libsodium в системных пакетах разных дистрибутивов разной версии.

## Решение
- `cmake/Dependencies.cmake` скачивает точные релизные архивы и проверяет SHA-256:
  libsodium 1.0.22 (сборка из исходников через `ExternalProject`, autotools, статически, `--disable-shared`),
  Catch2 3.16.1 и nlohmann/json 3.12.0 (`FetchContent`).
- Системные копии библиотек не используются; несовпадение хеша — ошибка конфигурации.
- Для офлайн-сборки архивы можно положить в каталог `YAP_DEPS_DIR`, хеши проверяются так же.

## Альтернативы
vcpkg (manifest + baseline) и Conan — приемлемы, но добавляют инструмент; при росте числа зависимостей (LMDB, protobuf,
Asio в M1.3/M2) решение можно пересмотреть новым ADR.
