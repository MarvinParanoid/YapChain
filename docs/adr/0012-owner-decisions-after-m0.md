# ADR-0012: Решения владельца проекта после M0

**Статус:** DECIDED · **Дата:** 2026-11-23

## Решения

| # | Решение | Влияние |
|---|---|---|
| 1 | CometBFT как отдельный Go-процесс — **принят** | ADR-0002 → DECIDED |
| 2 | Независимая сеть на базе P2P CometBFT — **принята** | ADR-0009 → DECIDED |
| 3 | Governance — multisig 3-of-5, реализация после M1 | ADR-0013 (закрывает OPEN ADR-0011) |
| 4 | Текущая экономика — **принята только для testnet** | economics.md: числа DECIDED для testnet; mainnet — OPEN |
| 5 | Мемпаспорт **не** является доказательством уникальности пользователя | attestations.md §6: нет правил «один человек — одна награда», Мемпаспорт — обычный эмитент |
| 6 | Лицензия — Apache-2.0 | файл `LICENSE`, SPDX-заголовки в исходниках |
| 7 | Поддерживаемые платформы — Linux x86_64 и Linux aarch64 | CI-матрица на обеих архитектурах; state roots сравниваются между ними |

## Последствия
- ADR-0002, ADR-0009 не переписываются; их статус DECIDED следует из этого ADR.
- Остальные PROPOSED-решения M0, уточнённые ревизией (ADR-0014…0019), принимаются вместе с этой ревизией.
