# Аудит ядра YapChain — M1.5

**Дата:** 2026-11-24 · **Объект:** состояние `main` после M1.4 (коммит `8b2fa82`) · **Вердикт:** PASS WITH FINDINGS —
все подтверждённые дефекты исправлены (ниже), оставшиеся пункты — информационные.

## Метод
- Четыре независимых ревьюера кода (криптография/кодек/кошелёк, state machine, хранилище/SMT, CLI) получили только
  код и спецификацию, без выводов автора; каждый воспроизводил находки собственными программами или через CLI.
- Отдельное исследование CometBFT по тегам репозитория (результат — [ADR-0026](adr/0026-cometbft-version.md) и
  [чек-лист](cometbft-compatibility.md)).
- Каждое исправление — отдельный коммит с регрессионным тестом; для ключевых (A1, A2) проверено, что тест падает на
  старом коде.

## Информационные пункты (не исправлялись)
| ID | Пункт | Почему оставлено |
|---|---|---|
| I1 | Отправитель с недетерминированным подписантом может получить несколько валидных подписей (разные `tx_id`) одного тела; исполнится одна (nonce) | свойство Ed25519; важно для дедупликации мемпула по `tx_id` (M2) |
| I2 | Парсер genesis JSON принимает BOM и `\u`-экранирование | на `genesis_hash` не влияет (хеш по YCS) |
| I3 | Инварианты после каждого блока проверяются только в debug-сборке | так в §7.3; узлы debug/release по-разному реагируют на баг |
| I4 | Контекстные ошибки в `ProcessProposal` — fail-stop, а не REJECT | корректно, пока CometBFT валидирует блок до вызова (чек-лист, CHECK) |
| I5 | `map_size` LMDB фиксирован (1 ГиБ), нет опции CLI | ошибка `StorageFull` явная; опция — при необходимости |
| I6 | `dev replay` коммитит поблочно: отказ в середине оставляет предыдущие блоки | каждый блок атомарен; поведение задокументировано |
| I7 | Целое число без суффикса — yip (`--amount 1` = 0.000001 YAP) | задокументировано; UX-риск |
| I8 | Вывод `keys list` не в формате `ключ: значение`; ошибки файла пароля — код 1 | косметика |
| I9 | Таблица `blocks` добавлена при версии схемы 1 | базы с 4 таблицами существовали только в тестах M1.3 |

## Проверено и признано корректным
YCS (3 млн мутаций — ни одного неканонического приёма), Ed25519 (совпадает с §5.2/§5.7, libsodium 1.0.22), domain
separation, Bech32m, checked-арифметика, порядок проверок S1–S11/T1–T7 при одновременных нарушениях, nonce/срок/TTL на
границах `U64_MAX`, атомарность tx, комиссии и эмиссия (все примеры economics.md), `last_commit`, genesis,
согласованность Process/Finalize, отсутствие источников недетерминизма, одна транзакция LMDB на высоту, отсутствие
двойной эмиссии, корректность и безопасность удаления узлов персистентного SMT (300×20 блоков без расхождений),
поведение при неверном пароле и повреждённом keystore.
